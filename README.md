## 🗺️ 지도 웹앱 (`index.html`)

- 지역(오사카/교토/고베/나라) · 카테고리 · **예약 방식(📱앱예약/☎️전화만/🎫원격줄서기/🚶현장방문)** · 등급(★★★) · 가격(¥~¥¥¥¥) 필터, 키워드 검색 (예: `TableCheck`, `OMAKASE`)
- 마커 클릭 → 설명, 대표 메뉴, 웨이팅 팁, 영업시간, 수상 이력 + **예약 앱 바로가기** + **구글 지도 / 길찾기(대중교통) / 타베로그 / 유튜브** 버튼
- ♥ 찜, ✓ 방문 체크 (브라우저에 저장) → "찜만 보기"로 내 동선 만들기
- 📍 내 위치순 정렬 (현지에서 "근처 레전드 맛집" 찾기)
- 링크 공유: `index.html#osaka-001` 처럼 가게 id 로 바로 열림

**여는 법**
1. **GitHub Pages** (레포가 공개이거나 GitHub Pro인 경우): Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `(root)` → 몇 분 뒤 `https://tkdrn416.github.io/matzip/` 에서 열림
2. **로컬**: 레포를 내려받아(Code → Download ZIP) `index.html` 더블클릭. 라이브러리는 레포에 포함돼 있어 서버 없이 열립니다(지도 타일만 인터넷 필요).

## 📱 구글 내 지도(My Maps)로 가져오기

여행 중에는 이게 제일 편합니다. 구글 지도 앱 → 저장됨 → 지도 에서 그대로 보입니다.

1. https://www.google.com/mymaps 접속 → **새 지도 만들기**
2. 레이어의 **가져오기** → `exports/google-mymaps/osaka.csv` 업로드
   - 위치 열: `위도`, `경도` 선택 → 제목 열: `이름`
3. 레이어 스타일 → **"카테고리" 열 기준으로 스타일 지정** → 종류별로 색이 나뉨
4. **레이어 추가** 후 `kyoto.csv`, `kobe.csv`, `nara.csv` 도 같은 방법으로 (지역별 레이어 4개)

> KML 파일(`*.kml`)도 있습니다. KML은 설명에 링크가 들어가 있지만 스타일 지정은 CSV가 더 편해요.

## 📅 예약 앱 가이드

DB의 모든 가게에 **온라인 예약 가능 여부**를 표시했습니다. 구글 지도 「예약」 버튼이든 앱이든, 온라인으로 예약이 되면 📱 **앱예약(온라인 예약 가능)** 입니다.

| 표시 | 의미 | 어떻게 하나 |
|---|---|---|
| 📱 **앱예약** = ✅ 온라인 예약 가능 | 구글 예약·타베로그·TableCheck·OMAKASE 등 온라인 예약 경로 확인됨 | `booking_apps` 의 링크로 바로 예약 |
| ☎️ **전화예약만** | 예약은 받지만 온라인 예약 없음 | 호텔 컨시어지에 부탁하거나 **AutoReserve**(AI 전화 대행) 사용 |
| 🎫 **원격줄서기** | 예약 불가, 번호표 앱/웹으로 원격 대기 | EPARK·Airウェイト·공식 LINE 등으로 번호표 → 근처에서 대기 |
| 🚶 **현장방문** | 예약 불가 | 오픈 전 줄 서기 (`tips` 참고) |
| ❔ 미확인 | 확인 못 함 | 타베로그 가게 페이지의 「予約可否」 확인 |

## ✍️ 맛집 추가·수정

1. `data/restaurants.json` 에 항목 추가/수정 (아래 스키마). `id`, `lat`, `lng` 는 비워두면 자동으로 채워집니다.
2. `python3 scripts/build.py` 실행 (파이썬 3.9+, 외부 패키지 없음)
   - 주소 → 좌표 변환은 일본 국토지리원(GSI) 주소 검색 API 사용
   - 좌표가 이상하면 `lat`, `lng` 를 직접 넣으면 그 값이 우선합니다
3. 커밋 & 푸시

### (선택) 구글 평점·리뷰 수 자동 채우기

구글 지도 평점은 Google Places API 키가 있어야 정확하게 가져올 수 있어서, 지금 DB에는 웹에서 확인된 값만 들어 있습니다.
키가 있다면 한 번에 채울 수 있어요:

```bash
export GOOGLE_MAPS_API_KEY=...          # Google Cloud 콘솔에서 Places API (New) 사용 설정
python3 scripts/google_places.py        # 평점·리뷰 수·구글 예약 표시·영업 상태 갱신
python3 scripts/build.py
```

평점 4.2 이상 & 리뷰 300개 이상이면 "구글" 선정 근거가 자동으로 붙고, 구글에 폐업으로 나오는 가게는 경고로 알려줍니다.

## 🏆 선정 기준

**모든 가게에 타베로그 점수를 표기**합니다 (가게 페이지에서 확인한 값, 조사 시점 기준). 타베로그 3.5 미만은 노포·원조·지역 상징처럼 특별한 이유가 있을 때만 넣었습니다.
참고로 타베로그는 3.5 이상이면 상위권, 3.8 이상이면 최상위권, 4.0 이상은 전국 톱클래스입니다.

그 위에 아래 중 하나 이상 + 여행자가 실제로 갈 수 있는 곳(소개제·회원제 제외), 2025~2026년 영업 확인:

- **타베로그**: 百名店(햐쿠메이텐), Tabelog Award, 고득점
- **미쉐린 가이드 교토·오사카/나라**: 별 · 빕 구르망
- **노포·원조**: 그 지역 음식을 대표하는 수십 년 이상 된 가게
- **유튜브**: 한국/해외 먹방·여행 유튜버가 소개한 곳 (실제 평판도 확인)
- **구글 지도**: 고평점 + 리뷰 다수

가게마다 `reasons` 필드에 **어떤 근거로 뽑혔는지**(예: "타베로그 3.78 · 라멘 백명점 2024", "성시경 먹을텐데 소개", "구글 4.5 / 리뷰 9,800+", "1946년 창업 키츠네우동 원조")를 출처 링크와 함께 적었습니다. 지도 팝업과 [목록](docs/LIST.md)에서 볼 수 있어요.

## ⚠️ 주의

- 영업시간·휴무·가격·타베로그 점수는 **조사 시점 기준**이며 수시로 바뀝니다. 방문 전 구글 지도/타베로그에서 꼭 다시 확인하세요.
- 좌표는 주소 기반 자동 변환이라 건물 단위로 약간 어긋날 수 있습니다. 실제 이동은 "구글 지도" 버튼(상호+주소 검색)을 쓰세요.
- 타베로그 링크는 **한국어판 가게 페이지**(tabelog.com/kr/…)로 연결됩니다. 점수·리뷰 수·예약 가능 여부를 한국어로 볼 수 있어요.
