### 🗺 (선택) 구글 지도 한국어 화면으로 보기

기본 지도는 무료 한국어 지도(OpenFreeMap)입니다. **구글 지도 한국어 화면**을 원하면 브라우저용 키를 하나 만들어 넣으세요.
(Actions 에 넣은 서버용 키와 **다른 키**로 만드세요 — 웹페이지에 들어가는 키라 사이트 제한이 꼭 필요합니다.)

1. Google Cloud 콘솔 → API 및 서비스 → 라이브러리 → **Map Tiles API** 사용 설정
2. 사용자 인증 정보 → API 키 만들기 → 키 제한
   - 애플리케이션 제한: **웹사이트** → `https://tkdrn416.github.io/*`
   - API 제한: **Map Tiles API** 만
3. (권장) Map Tiles API → 할당량에서 하루 요청 상한을 걸어 요금 폭주 방지
4. 폰에서 `https://tkdrn416.github.io/matzip/#gkey=만든키` 를 **한 번** 열기(카톡 '나에게 보내기' 등) → 그 폰에 저장되고 주소에서 지워짐. 또는 지도 오른쪽 위 **⚙️ 지도 설정**에 붙여넣기
   - 모든 기기에 쓰려면 `assets/config.js` 의 `googleMapsKey` 에 넣어 커밋해도 됩니다(공개되므로 2번 제한 필수)

## 📱 구글 내 지도(My Maps)로 가져오기

여행 중에는 이게 제일 편합니다. 구글 지도 앱 → 저장됨 → 지도 에서 그대로 보입니다.

1. https://www.google.com/mymaps 접속 → **새 지도 만들기**
2. 레이어의 **가져오기** → `exports/google-mymaps/osaka.csv` 업로드
   - 위치 열: `위도`, `경도` 선택 → 제목 열: `이름`
3. 레이어 스타일 → **"카테고리" 열 기준으로 스타일 지정** → 종류별로 색이 나뉨
4. **레이어 추가** 후 `kyoto.csv`, `kobe.csv`, `nara.csv` 도 같은 방법으로 (지역별 레이어 4개)

> KML 파일(`*.kml`)도 있습니다. KML은 설명에 링크가 들어가 있지만 스타일 지정은 CSV가 더 편해요.

가게마다 **온라인 예약 가능 여부**를 표시했습니다. 온라인으로 예약되는 경로(타베로그 넷예약·TableCheck·OMAKASE·공식 예약폼·핫페퍼 등)를 찾으면 📱 **앱예약(온라인 예약 가능)** 입니다.
"온라인 예약 없음"은 **타베로그(전 가게)와 핫페퍼(75곳)를 직접 확인한 결과**입니다. 구글 정보(예약 받음 여부, 전화 포함)는 참고로 함께 표시하고, 구글맵의 「예약」 버튼 자체는 확인하지 못했습니다.

| 표시 | 의미 | 어떻게 하나 |
|---|---|---|
| 📱 **앱예약** = ✅ 온라인 예약 가능 | 구글 예약·타베로그·TableCheck·OMAKASE 등 온라인 예약 경로 확인됨 | `booking_apps` 의 링크로 바로 예약 |
| ☎️ **전화예약만** | 예약은 받지만 온라인 예약 없음 | 호텔 컨시어지에 부탁하거나 **AutoReserve**(AI 전화 대행) 사용 |
| 🎫 **원격줄서기** | 예약 불가, 번호표 앱/웹으로 원격 대기 | EPARK·Airウェイト·공식 LINE 등으로 번호표 → 근처에서 대기 |

### (선택) 구글 평점·리뷰 수 자동 채우기

구글 지도 평점은 Google Places API 키가 있어야 정확하게 가져올 수 있어서, 지금 DB에는 웹에서 확인된 값만 들어 있습니다.
키가 있다면 한 번에 채울 수 있어요:

```bash
export GOOGLE_MAPS_API_KEY=...          # Google Cloud 콘솔에서 Places API (New) 사용 설정
python3 scripts/google_places.py        # 평점·리뷰 수·구글 예약 표시·영업 상태 갱신
python3 scripts/build.py
```

평점 4.2 이상 & 리뷰 300개 이상이면 "구글" 선정 근거가 자동으로 붙고, 구글에 폐업으로 나오는 가게는 경고로 알려줍니다.

**GitHub Actions 로 실행 (권장)**: 레포 Settings → Secrets and variables → Actions 에 `GOOGLE_MAPS_API_KEY` 를 등록하고,
Actions 탭 → "구글 평점 채우기 (Google Places)" → Run workflow. 결과는 자동으로 main 에 커밋됩니다.

403 `PERMISSION_DENIED` 가 나오면 Google Cloud 콘솔에서:
1. **API 및 서비스 → 라이브러리 → "Places API (New)"** 사용 설정 (예전 "Places API" 와 다른 항목)
2. 프로젝트에 **결제 계정** 연결
3. **사용자 인증 정보 → API 키 → 제한사항**: 애플리케이션 제한은 "없음"(Actions 서버 IP 가 매번 바뀜), API 제한에 "Places API (New)" 포함

- **오사카 나폴리탄 10곳 더**(기준을 "나폴리탄 평이 좋은 킷사텐·양식집"까지 넓힘, 오사카 메트로 공식 '나폴리탄 매니아' 특집·타베로그 후기로 확인) → "나폴리탄" 검색 19곳.
- **나폴리탄 재검증**: 사용자가 "구글맵에 나폴리탄 리뷰가 거의 없다"고 지적 → 18곳의 최근 타베로그 후기 40개씩을 세어 등급을 매김. **명물(A) 3곳**(로마스파 정열의 나폴리탄 31/40, 오사카 나폴리탄 26/40, 모덴 13/40), **인기 메뉴(B) 5곳**, **메뉴에 있음(C)** 나머지. 기사·특집엔 나폴리탄으로 나왔지만 실제 후기는 푸딩·케이크·달걀 샌드위치 위주인 곳(토키오나·마드라그·스이게이 등)은 대표 메뉴를 실제 후기 기준으로 바꾸고, 나폴리탄 하나로 넣었던 3.4점대 2곳(쇼치쿠·마치노아카리)은 뺌. "나폴리탄" 검색은 명물 → 인기 → 메뉴에 있음 순, 가게 상세에 근거 링크·나폴리탄 사진 검색·"구글맵 리뷰는 「ナポリタン」으로 검색" 안내.
- **이자카야**: 이자카야 백명점(WEST 2026) 중 빠졌던 오사카·고베 10곳·교토 14곳 + **다치노미 백명점 2025** 중심의 대중 이자카야·다치노미 11곳(난바·도톤보리·우라난바 6곳). 이자카야 카테고리 22 → 55곳, "이자카야" 검색은 쿠시카츠·가성비 야키토리·오뎅 등 술 마시기 좋은 곳까지 102곳.
- **구글 리뷰 레전드 × 타베로그 교차 검증**: 구글 지도에서 동네×음식별로 평점 높고 리뷰 많은 곳 589곳을 모았는데(이 중 DB에 이미 있던 곳 14곳), 체인을 빼고 상위 150곳을 타베로그로 확인하니 **타베로그 3.45 이상은 14곳(9%)**뿐 — 체인 46곳, 타베로그 3.45 미만 82곳(중앙값 3.26), 타베로그 미등록 8곳. 간사이의 구글 고평점은 관광객 리뷰·리뷰 이벤트 영향이 커서, 구글과 타베로그 **둘 다 인정하는 14곳만** 넣었습니다(라멘 NEXT□·초로, 야키토리 토리나, 니쿠료리 아라카와, 기온 스시 타쿠 등). 후보 목록은 `data/google_candidates.json`, 다시 돌리려면 Actions → "구글 레전드 후보 찾기".

뺀 곳(27곳): 폐점·이전 예정, 소개제·일견 거절, 인스타그램 DM으로만 예약, 전화·온라인 예약 경로 없음, 2025~2026 영업 확인 안 됨, 타베로그 3.3 미만.
도심에서 먼 곳(나라 남부·교외)은 명단 2개 이상 겹친 곳만 넣었습니다.

### 신뢰도(✔) 표시

가게마다 **서로 독립적인 근거 수**를 셉니다: 타베로그 3.6+ · 백명점 · Tabelog Award · 미쉐린 · 구글 4.2+(리뷰 300+) · 유튜브 · 노포·원조 · 언론·가이드.
목록 카드의 **근거 N** 배지와 상세의 "신뢰도" 줄에서 볼 수 있고, **근거 3개+** 필터로 근거 3개 이상인 곳만 볼 수 있어요.
참고로 타베로그와 구글 평점은 거의 상관이 없습니다(1차 255곳 기준 r≈0.19). 타베로그는 맛, 구글은 관광객 만족도(친절·편의)에 가깝다고 보고 타베로그를 우선합니다.

가게마다 `reasons` 필드에 **어떤 근거로 뽑혔는지**(예: "타베로그 3.78 · 라멘 백명점 2024", "성시경 먹을텐데 소개", "구글 4.5 / 리뷰 9,800+", "1946년 창업 키츠네우동 원조")를 출처 링크와 함께 적었습니다. 지도 팝업과 [목록](docs/LIST.md)에서 볼 수 있어요.

## 🔍 데이터의 한계

솔직하게 적어 둡니다.

- **구글 평점·리뷰 수**: Google Places API 로 1차 **252/255곳** 채움 (2026-11-21, GitHub Actions). 2차 확장분은 같은 워크플로를 `only_missing` 으로 돌려 채웁니다. 평점 4.2+ & 리뷰 300+ 인 130곳엔 "구글" 선정 근거가 붙었습니다. 지도 핀도 구글 좌표로 보정했습니다. 구글이 다른 가게를 가리키는 것으로 보인 곳(상호·거리 불일치)은 건너뛰었습니다.
- **구글 '예약 받음' 표시**: Places API 의 예약 정보는 **전화 예약을 포함**한 "예약 받음" 여부라서 온라인 예약과 다릅니다. 앱에도 그렇게 표시합니다.
- **유튜브 근거**: 실제 영상으로 확인된 추천만 넣어서 십여 곳뿐입니다 (또간집, 먹을텐데, Mark Wiens 등). 쯔양·백종원·곽튜브 등은 간사이 식당 방문 영상을 확인하지 못했습니다. 카드의 "▶ 유튜브 검색"은 검색 링크입니다.
- **구글맵 온라인 예약 버튼**: Places API 로는 '구글맵에서 바로 예약' 버튼 유무를 알 수 없습니다. "온라인 예약 없음"인 가게도 구글맵 화면에 「예약」 버튼이 있을 수 있으니 한 번 확인해 보세요.
- **확장분 미쉐린 등급**: 타베로그 페이지엔 미쉐린 표시가 없어, 명단에 등급이 없던 곳은 "미쉐린 가이드 게재"로만 적었습니다.
- **온라인 예약 링크 없는 '앱예약'**: OMAKASE·포켓컨시어지로만 받는데 가게가 링크를 공개하지 않은 곳(10여 곳)은 예약 메모에 방법을 적었습니다. 해당 앱에서 가게 이름으로 검색하세요.
- **업종 편중**: 화과자·카페·빵이 교토·나라에서 비중이 큽니다 (그 지역의 명물이기도 함). 필터로 걸러 보세요.

## ⚠️ 주의

- 영업시간·휴무·가격·타베로그 점수는 **조사 시점 기준**이며 수시로 바뀝니다. 방문 전 구글 지도/타베로그에서 꼭 다시 확인하세요.
- "🟢 지금 입장 가능"은 요일별 영업시간·라스트오더 기준입니다. 공휴일 휴무(⚠️ 표시), n째 주 휴무·재료 소진("휴무일 변동 있음" 표시), 연말연시는 완벽히 반영되지 않습니다. 타베로그에 영업시간이 비어 있던 요일 일부(23곳)는 구글 지도 영업시간으로 채웠습니다(상세의 '영업참고'에 표시).
- **흡연 정보**는 타베로그 「禁煙・喫煙」 칸 기준이라 가게가 갱신하지 않았으면 다를 수 있습니다. 일본은 2020년부터 원칙적으로 실내 금연이지만 작은 이자카야·킷사텐 등은 '흡연 가능 가게'로 신고할 수 있고, 그런 가게는 **입구에 「喫煙可能店」「喫煙可」 표지**를 붙여야 하니 들어가기 전에 한 번 보세요.
- 웨이팅은 최근 후기에서 본 **일반적인 대기 시간(피크 기준) 예상치**입니다. 실시간 정보가 아니며 요일·시즌·날씨에 따라 크게 달라질 수 있어요.
- 좌표는 주소 기반 자동 변환이라 건물 단위로 약간 어긋날 수 있습니다. 실제 이동은 "구글 지도" 버튼(상호+주소 검색)을 쓰세요.
- 타베로그 링크는 **한국어판 가게 페이지**(tabelog.com/kr/…)로 연결됩니다. 점수·리뷰 수·예약 가능 여부를 한국어로 볼 수 있어요.
